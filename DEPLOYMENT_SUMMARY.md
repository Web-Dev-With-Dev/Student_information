## 🚀 Deploy in 6 Minutes

### Frontend (Vercel) - 2 Minutes
1. Go to: https://vercel.com/dashboard
2. Click "New Project" → Import GitHub
3. Select `Student_information`
4. Add environment: `GEMINI_API_KEY`
5. Click Deploy

**Get URL**: `https://your-app-name.vercel.app`

### Backend (Railway) - 3 Minutes
1. Go to: https://railway.app/dashboard
2. Click "New Project" → Deploy from GitHub
3. Select `Student_information`
4. Add MySQL service (automatic)
5. Add backend service (`/backend` folder)
6. Railway provides all MySQL credentials automatically!
7. You just set: `NODE_ENV`, `CORS_ORIGIN`
8. Click Deploy

**Get URL**: `https://your-backend-name.railway.app`

### Connect - 1 Minute
1. Update Vercel `VITE_API_URL` to backend URL
2. Vercel auto-redeploys
3. Done! ✅
